This file outlines the steps to deploy the TRAFx application to Google Cloud Platform (GCP).

**Prerequisites:**

1.  **Google Cloud Account:** You need a GCP account with an active project.
2.  **gcloud CLI:** Install and configure the Google Cloud CLI.
    *   Installation: https://cloud.google.com/sdk/docs/install
    *   Configuration: `gcloud init`

**Step 1: Set up Google Cloud Services**

1.  **Enable APIs:** Enable the necessary APIs for the project.
    ```bash
    gcloud services enable appengine.googleapis.com
    gcloud services enable firestore.googleapis.com
    gcloud services enable cloudbuild.googleapis.com
    ```

2.  **Create a Firestore Database:**
    *   Go to the Firestore console: https://console.cloud.google.com/firestore
    *   Choose "Native mode". **This is very important. Do not select "Datastore mode".**
    *   Select a location for your database.

3.  **Set up SendGrid for Email:**
    *   Go to the SendGrid page in the GCP Marketplace: https://console.cloud.google.com/marketplace/product/sendgrid-inc/sendgrid-email
    *   Click "Subscribe" and follow the instructions to set up your SendGrid account.
    *   Once your account is set up, create an API key. You will use this in your application.

4.  **Create an App Engine application:**
    *   Run the following command and choose a region when prompted.
    ```bash
    gcloud app create
    ```

**Step 2: Configure the Application for GCP**

1.  **Create `app.yaml`:** This file configures the App Engine deployment. Create a new file named `app.yaml` in the root of your project with the following content:

    ```yaml
    runtime: python39
    entrypoint: gunicorn -b :$PORT app:app

    env_variables:
      SENDGRID_API_KEY: 'YOUR_SENDGRID_API_KEY'

    handlers:
    - url: /static
      static_dir: static
    - url: /.*
      script: auto
    ```
    **Note:** Replace `YOUR_SENDGRID_API_KEY` with your actual SendGrid API key.

2.  **Create `cloudbuild.yaml`:** This file defines the build and deployment process for Cloud Build. Create a new file named `cloudbuild.yaml` in the root of your project with the following content:

    ```yaml
    steps:
    - name: 'gcr.io/cloud-builders/pip'
      args: ['install', '-r', 'requirements.txt']
    - name: 'gcr.io/cloud-builders/gcloud'
      args: ['app', 'deploy']
    ```

3.  **Update `requirements.txt`:** Add the necessary GCP and SendGrid libraries.

    ```
    Flask
    google-cloud-firestore
    gunicorn
    sendgrid
    ```

**Step 3: Modify the Application Code**

*   You need to modify the application to use Firestore instead of `data.json` and SendGrid for emails. I can help with this in the next step.

**Step 4: Deploy the Application**

1.  **Submit the build:** Run the following command from your project's root directory.

    ```bash
    gcloud builds submit --config cloudbuild.yaml
    ```

2.  **View your application:** After the build is complete, you can view your application by running:

    ```bash
    gcloud app browse
    ```
